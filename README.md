# Vedika Bhoir — Data Analyst Portfolio

Single-file portfolio site (`index.html`), no build step.

## Publish on GitHub Pages (5 minutes)
1. Create a public repo named **`<your-github-username>.github.io`**.
2. Upload `index.html` and all three `.jpg` photos (and this README) to the repo root — keep them together.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Site goes live at `https://<your-github-username>.github.io`.

## Before sharing with recruiters
- Search `index.html` for `TODO` and `YOUR-GITHUB-USERNAME`.
- Replace every `href="#"` on the orange dashed **code / dashboard / notebook / demo** buttons with real links.
- Each project repo should have: a README (problem, dataset, approach, key findings),
  the notebook or `.sql` file, and 1–2 screenshots of charts or the Power BI dashboard.
